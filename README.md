# 깜빡이는 우체부

우체부를 방향키로 움직이고 클릭해서 인사하는 팀 작품입니다. 고리몽은 우체부의 등을, 도란몽은 인사 소리를 맡았습니다.

[VPyLab에서 깜빡이는 우체부 실행하기](https://vpylab.pages.dev/sandbox?repo=greatsong/vpylab-workshop-postman&autorun=1&view=run)

## 이렇게 해 보세요

1. 실행 화면에서 시작을 누릅니다.
2. 좌우 방향키로 우체부를 움직입니다.
3. 우체부를 두 번 눌러 머리의 등과 인사 소리가 어떻게 달라지는지 비교합니다.

![우체부의 머리 위에 주황색 등이 켜진 장면](우체부.webp)
